Introducción: ¿Qué vamos a estudiar?

¿Qué vamos a estudiar?

En este tema vamos a estudiar las redes informáticas, es decir, la forma en que diferentes dispositivos pueden conectarse entre sí para intercambiar información y compartir recursos.

Vamos a conocer:

  • qué es una red informática;
  • cuáles son sus elementos principales;
  • cómo funciona Internet;
  • qué es la conmutación de paquetes;
  • qué diferencias existen entre Internet, Intranet y Extranet;
  • cómo funcionan los modelos cliente/servidor y P2P;
  • qué es un sistema operativo de red;
  • y cómo se clasifican las redes según su alcance: LAN, MAN y WAN.

¿Por qué es importante?

Las redes están presentes prácticamente en todas nuestras actividades digitales. Cuando enviamos un mensaje, miramos un video, usamos una computadora conectada al Wi-Fi, imprimimos un documento desde otro equipo o ingresamos a una página web, estamos utilizando una red.

Comprender cómo funcionan permite entender mejor la tecnología que utilizamos todos los días.

¿Dónde encontramos redes en la vida cotidiana?

  • 📱 Un celular conectado al Wi-Fi.
  • 💻 Computadoras conectadas en una escuela.
  • 🖨️ Varias computadoras utilizando una misma impresora.
  • 🎮 Personas jugando en línea.
  • 🏢 Computadoras conectadas dentro de una empresa.
  • 🌎 Una persona accediendo a una página web alojada en otro país.

¿Qué es una red informática?

¿Qué es una red informática?

Una red informática es un conjunto de dos o más dispositivos conectados entre sí para poder comunicarse, intercambiar información y compartir recursos.

Los dispositivos pueden conectarse mediante cables o de forma inalámbrica.

Ejemplo: Celular → Wi-Fi → Router → Internet

El celular se conecta al router mediante Wi-Fi y el router permite comunicarse con otros dispositivos y con Internet.

Características de una red

  • Permite compartir información.
  • Permite compartir recursos.
  • Facilita la comunicación.
  • Puede utilizar conexiones cableadas o inalámbricas.
  • Puede ser pequeña, como una red doméstica, o enorme, como Internet.

Elementos básicos de una red

Para que una red pueda funcionar necesita diferentes componentes.

💻 Dispositivos finales

Son los equipos que utilizan los usuarios.

  • computadoras;
  • celulares;
  • tablets;
  • impresoras;
  • servidores;
  • cámaras IP.

🔀 Switch

Es un dispositivo que permite conectar diferentes equipos dentro de una misma red local. Por ejemplo, en una escuela puede conectar varias computadoras entre sí.

📡 Router

Permite conectar diferentes redes y dirigir los datos hacia su destino. En una casa, por ejemplo, el router permite conectar nuestros dispositivos a Internet.

📶 Punto de acceso

Permite conectar dispositivos de manera inalámbrica mediante Wi-Fi.

🔗 Medio de transmisión

Es el camino por el cual viajan los datos. Puede ser:

  • cable de red;
  • fibra óptica;
  • ondas de radio/Wi-Fi.

Internet

Internet

Internet es una enorme red mundial formada por millones de redes y dispositivos conectados entre sí. Permite que personas y organizaciones de diferentes lugares puedan intercambiar información y utilizar servicios digitales.

Algunos servicios que utilizamos mediante Internet

  • páginas web;
  • correo electrónico;
  • videollamadas;
  • redes sociales;
  • videojuegos online;
  • almacenamiento en la nube;
  • plataformas educativas;
  • servicios de streaming.

Ejemplo cotidiano

Cuando buscamos información en Google desde nuestro celular, nuestro dispositivo envía una solicitud a través de diferentes redes hasta llegar al servidor que contiene la información. Luego la respuesta vuelve hasta nuestro dispositivo.

Estructura general de Internet

Internet no funciona como una única computadora gigante. Está formada por una gran cantidad de redes interconectadas. La información puede atravesar diferentes redes y dispositivos antes de llegar a su destino.

Conmutación de paquetes

Conmutación de paquetes

La conmutación de paquetes es una técnica utilizada para enviar información a través de una red.

En lugar de enviar toda la información como un único bloque, los datos se dividen en pequeñas unidades llamadas paquetes. Cada paquete contiene información necesaria para poder llegar a su destino.

¿Cómo funciona?

Cuando enviamos una foto por Internet, la información de la foto puede dividirse en paquetes. Estos viajan por la red y al llegar al dispositivo receptor se vuelven a organizar para reconstruir la imagen.

Ventaja

Permite utilizar la red de manera eficiente porque diferentes comunicaciones pueden compartir los mismos caminos.

Internet, Intranet y Extranet

Intranet

Una Intranet es una red privada que utiliza tecnologías similares a las de Internet, pero está destinada a los miembros de una organización.

Por ejemplo, una empresa puede tener una página interna donde sus empleados consultan documentos, horarios, comunicados, información interna y recursos de trabajo.

Extranet

Una Extranet es una red privada que permite que determinadas personas externas a una organización puedan acceder a algunos recursos.

Por ejemplo, una empresa puede permitir que sus proveedores ingresen a una plataforma para consultar pedidos o información específica.

Para recordar

Internet→ todos
Intranet→ organización interna
Extranet→ organización + externos autorizados

Modelo Cliente/Servidor

Modelo cliente/servidor

El modelo cliente/servidor es una forma de organizar una red en la que:

  • el cliente solicita un servicio;
  • el servidor proporciona ese servicio.

Ejemplo

Cuando ingresamos a una página web:

  • Nuestro navegador = cliente
  • Computadora que almacena la página = servidor

El cliente realiza una solicitud y el servidor responde.

Ventajas

  • Facilita la administración.
  • Permite centralizar información.
  • Facilita realizar copias de seguridad.
  • Permite controlar los accesos.

Desventaja

Si el servidor principal presenta un problema, los usuarios pueden perder el acceso al servicio.

Modelo Peer-to-Peer (P2P)

Modelo Peer-to-Peer (P2P)

Peer-to-Peer significa “entre pares”.

En este modelo, los dispositivos pueden comunicarse directamente entre sí sin depender necesariamente de un servidor central. Cada dispositivo puede actuar como cliente y como proveedor de recursos.

Ejemplo

Una red donde varias computadoras comparten archivos directamente entre ellas.

Ventajas

  • No necesita necesariamente un servidor central.
  • Puede ser sencilla de implementar.
  • Los dispositivos pueden compartir recursos directamente.

Desventajas

  • Puede ser más difícil de administrar.
  • La seguridad puede ser más complicada.
  • No resulta ideal para redes empresariales grandes.

Sistemas operativos de red

Sistemas operativos de red

Un sistema operativo de red es un sistema diseñado para administrar y facilitar los recursos y servicios de una red informática.

Permite que los dispositivos puedan comunicarse y que los usuarios puedan acceder a recursos de manera organizada y segura.

Funciones principales

  • Administrar usuarios.
  • Controlar permisos.
  • Compartir archivos.
  • Administrar impresoras.
  • Gestionar recursos de red.
  • Proporcionar seguridad.
  • Administrar conexiones.
  • Realizar determinadas tareas de mantenimiento.

Tipos

Podemos encontrar sistemas utilizados principalmente en servidores, como:

  • Windows Server.
  • Linux para servidores.
  • UNIX y sistemas derivados.

Clasificación: LAN, MAN y WAN

Clasificación de redes según su alcance

Las redes pueden clasificarse según el área geográfica que cubren.

LANLocal Area Network — Red de Área Local
MANMetropolitan Area Network — Red de Área Metropolitana
WANWide Area Network — Red de Área Amplia

LAN

Una LAN conecta dispositivos dentro de un área relativamente pequeña.

Ejemplos: una casa, un aula, una escuela, una oficina.

  • Alcance reducido.
  • Generalmente pertenece a una persona u organización.
  • Suele tener buena velocidad.
  • Puede utilizar Ethernet o Wi-Fi.

MAN

Una MAN conecta diferentes redes dentro de un área metropolitana, generalmente una ciudad o una zona urbana extensa.

Ejemplo: una organización que posee diferentes edificios dentro de una misma ciudad y necesita conectar las redes de cada edificio.

  • Mayor alcance que una LAN.
  • Puede conectar diferentes LAN.
  • Puede abarcar una ciudad o zona metropolitana.

WAN

Una WAN conecta redes ubicadas a grandes distancias. Puede conectar ciudades, países e incluso diferentes continentes.

Ejemplo: Internet es el ejemplo más conocido de una red de alcance mundial que interconecta redes.

  • Gran cobertura geográfica.
  • Puede conectar diferentes ciudades y países.
  • Interconecta múltiples redes.
  • Puede utilizar diferentes tecnologías de comunicación.
