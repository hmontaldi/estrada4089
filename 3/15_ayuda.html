Cómo utilizar la maqueta

  1. Ingresá desde Inicio y abrí el índice del curso.
  2. Elegí un módulo desde la barra lateral o las tarjetas.
  3. Usá “Marcar módulo como revisado” para actualizar el avance.
  4. Practicá y completá la evaluación.
  5. Si alcanzás el 60 %, se habilita el enlace al certificado demostrativo.
  6. Para generar un PDF, usá “Imprimir / Guardar PDF”.
Los datos se guardan con localStorage en el navegador actual. Borrar los datos del navegador o usar otro dispositivo puede reiniciar el progreso.

Alcance técnico

HTML estructura las pantallas, CSS define la apariencia y JavaScript implementa navegación auxiliar, corrección y estado local. No existe Back End ni base de datos.
