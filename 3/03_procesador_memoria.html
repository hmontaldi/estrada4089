Procesador y memoria

La CPU ejecuta instrucciones y coordina operaciones. La memoria permite conservar temporalmente datos e instrucciones necesarios para el trabajo del sistema.

⚙️

Conceptos clave

  • CPU: interpreta y ejecuta instrucciones.
  • La memoria RAM mantiene temporalmente datos e instrucciones en uso.
  • La caché ayuda a reducir el tiempo de acceso a datos frecuentes.
Ejemplo: al abrir un programa, sus instrucciones y datos se cargan en memoria para que el procesador pueda trabajar.

Relación entre componentes

CPU ↔ memoria RAM ↔ almacenamiento
